# Beach Tennis Control — PWA

Versão atual preparada para GitHub Pages e iPhone.

## Arquivos
- `index.html` — aplicativo atualizado
- `manifest.json` — configuração PWA
- `sw.js` — cache/offline
- `icons/` — ícones

## GitHub Pages
1. Crie um repositório no GitHub.
2. Envie todos os arquivos desta pasta para a raiz.
3. Confirme que `index.html` está na raiz.
4. Vá em **Settings → Pages**.
5. Escolha **Deploy from a branch**, branch **main** e pasta **/ (root)**.
6. Salve e aguarde a publicação.
7. Abra o endereço `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## iPhone
Abra o site no Safari → **Compartilhar** → **Adicionar à Tela de Início**.

Os dados do torneio ficam no armazenamento do navegador/dispositivo e não são sincronizados pelo GitHub Pages.
